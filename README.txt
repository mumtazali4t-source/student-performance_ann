# Student Performance Prediction using ANN

## Files
- `Student_Performance_ANN_Project.ipynb` — complete Jupyter Notebook.
- `student_performance_dataset.csv` — 500 synthetic practice records.

## Run
1. Install Python and Jupyter (or use Jupyter support in VS Code).
2. Open this folder.
3. Open `Student_Performance_ANN_Project.ipynb`.
4. Run the cells from top to bottom.
5. If required, run `%pip install pandas numpy matplotlib seaborn scikit-learn`.

## Important
The included dataset is synthetic, created for education and practice. Model metrics are only demonstration results and do not represent real-world student prediction performance.
